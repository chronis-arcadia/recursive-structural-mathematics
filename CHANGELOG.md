# Changelog

## [0.2.0] — 2026-09-21

### Research reset

- Withdrawn the claim that recursive stability is a truth predicate.
- Removed "Goedel bypass", post-proof replacement, observer-neutral truth, and self-validating adversarial-audit claims from the active specification.
- Reframed RSM as profile-dependent recursive structural stability / drift analysis.
- Replaced generic "entropy" terminology with explicit drift metrics except where entropy is genuinely defined.
- Redefined C1/C2/C3 as stability regimes rather than truth classes.
- Added a hard separation between external correctness and recursive stability.
- Reframed RIPE as a measurement engine, SDL as abstention/uncertainty gating, and CPP as a trust-boundary/versioning rule.
- Added falsifiable experimental protocol and negative controls.
- Added dependency-free Python reference implementation and unit tests.
- Replaced the old string-reversal notebook with a sanity demo that explicitly exposes its two-cycle artifact.
- Replaced CDD v0 with a calibration set containing stable falsehood and transform-dependence controls.
- Removed obsolete generated equation media from the active tree.
